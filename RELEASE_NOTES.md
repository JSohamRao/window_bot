# THUKUNA 0.1.0

Initial Windows x64 desktop release.

- Transparent, frameless THUKUNA desktop companion with the approved 116-frame sprite library.
- Autonomous idle, crawl, sprint, jump, hop, fall, climb, perch, sleep, cursor-aware, reaction, Rage, rare-event, and Domain Expansion behaviors.
- Dragging and bounded two-dimensional movement across the usable desktop work area.
- Native tray controls for visibility, behavior settings, always-on-top, safe position reset, startup launch, and exit.
- Persistent local settings, Chaos Mode, Low Power Mode, and single-instance behavior.
- Sandboxed renderer with context isolation enabled and Node integration disabled.
- Assisted per-user NSIS installation with Start menu and desktop shortcuts.

This release is not code-signed. Windows may identify the installer publisher as unknown.
